# Matplotlib Style Sheets for Scientific Plotting.
A small collection of Matplotlib style sheets that I used for my Master's thesis. Mainly intended for my own personal use, but you are free to use them. Compatible to use in Jupyter Notebooks/Google Colab.

<img src="./img/fjv-scientific1 example.png" width=800>
<em>^Made using fjv-scientific1.mplstyle</em>

## How to Use
After ```import matplotlib as plt```, put this line immediately after:
```python
plt.style.use('https://github.com/FVilimek/fjv_matplotlib_stylesheets/raw/main/[style sheet].mplstyle')
```
You should be good to go. <br>
Color palette borrowed from <a href="https://github.com/nicoguaro/matplotlib_styles/blob/master/README.md">matplotlb_style</a> by nicoguaro. <br>
If you want an indispensable resource for style sheets, see the <a href="https://matplotlib.org/stable/users/explain/customizing.html">Matplotlib documentation</a>.
